# Supabase Database Seed Setup

These SQL files represent the PostgreSQL schema structure and seed datasets matching the initial mock data of the Field Credit Collection app.

## Contents
1. `001_schema_placeholder.sql` - Complete schema, index optimizations, and running balance database views.
2. `002_sample_data.sql` - Sample seed records matching our mock repository datasets.

## How to Apply to Supabase
1. Install Supabase CLI.
2. Link your local project: `supabase link --project-ref <your-project-ref>`
3. Run migrations or apply directly in the SQL Editor on your Supabase dashboard:
   - Copy contents of `001_schema_placeholder.sql` and run.
   - Copy contents of `002_sample_data.sql` and run.
